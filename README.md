# Greener Pastures Farm Website

A static HTML, CSS, and JavaScript website for an equestrian facility. This website features:

- Responsive design that works on all device sizes
- Parallax scrolling background effect
- Testimonial slider
- Contact form with validation
- Modern and clean UI design

## Project Structure

- `index.html` - Main HTML structure
- `styles.css` - CSS styling including parallax effects
- `script.js` - JavaScript for interactivity and animations
- `images/` - Directory containing all images used in the website

## Features

1. **Parallax Scrolling Background**
   - Creates depth and visual interest as users scroll
   - Implemented with CSS transforms and JavaScript

2. **Responsive Layout**
   - Mobile-friendly design
   - Flexbox and CSS Grid for modern layouts
   - Media queries to adjust for different screen sizes

3. **Interactive Elements**
   - Testimonial slider with automatic and manual navigation
   - Form validation
   - Smooth scrolling navigation

4. **Performance Optimized**
   - Efficient JavaScript
   - Optimized image loading

## How to Use

Simply open the `index.html` file in any modern web browser to view the website.

## Customization

To customize this website:

1. Replace the images in the `images` folder with your own
2. Update the text content in `index.html`
3. Adjust colors and styling in `styles.css`
4. Modify any functionality in `script.js` as needed
